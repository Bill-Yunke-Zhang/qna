# QnA Deployment Notes

## Production server

The QnA production server is a Google Cloud VM named production-web-server.
It runs in the us-central1-a zone on an e2-standard-4 machine,
which has 4 vCPUs and 16 GB of memory and no GPU.

## AI services

The live answering profile is sliding-window with the all-MiniLM-L6-v2 embedding model.
Answers are generated by qwen2.5:1.5b running in Ollama on the same VM.
A question is answered only when a source scores at or above the similarity threshold.

## Deploying

Merging main into the protected production branch starts the deploy pipeline,
which builds the nginx and backend images and restarts them on the VM.
